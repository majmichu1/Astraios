Install Astraios

Every installer is small. It creates a private Python environment, detects your GPU and downloads the matching PyTorch build (about 2 GB for CUDA), so there is no Python setup and no manual CUDA install. Get the files from the latest release (v0.1.25-alpha).

Which GPU is used

Astraios picks CUDA, then Apple Metal, then CPU, automatically, and prints the device in the log panel at startup. AMD and Intel GPUs are not accelerated. Set ASTRAIOS_FORCE_CPU=1 to force the CPU. Large images are processed in tiles so 4 to 8 GB of VRAM is enough; on a CUDA out-of-memory error the operation falls back to the CPU.

Updating and integrity

Astraios checks GitHub for a newer release at startup (Preferences > Updates to turn it off) and can download the installer for you. Releases built after September 2026 publish a .sha256 sidecar per asset; the updater verifies against it, and you can check by hand with sha256sum -c or Get-FileHash.

Troubleshooting

  • Expected CUDA but the log says CPU: update the NVIDIA driver and run the installer again.
  • Linux desktop entry missing: log out and back in.
  • Anything else: open an issue with the log panel output, or read docs/installation.md.
