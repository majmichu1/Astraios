# Support

Astraios is alpha software maintained by one person in their spare time.
Here is where to go for what.

- **Questions and how-to** (which stacking setting, how to process an OSC
  image, does it run on my machine): [GitHub Discussions](https://github.com/majmichu1/Astraios/discussions).
- **Bugs**: [open an issue](https://github.com/majmichu1/Astraios/issues/new?template=bug_report.md)
  with the log panel output, your OS, GPU and the file format involved.
- **Compatibility reports** (it works, or does not, on your hardware):
  [compatibility report form](https://github.com/majmichu1/Astraios/issues/new?template=compatibility_report.yml).
  The table of verified platforms in [docs/project-facts.md](docs/project-facts.md#compatibility-ci-tested-versus-user-verified)
  is built from CI runs and these reports.
- **Feature requests**: [feature request form](https://github.com/majmichu1/Astraios/issues/new?template=feature_request.md).
- **Security**: see [SECURITY.md](SECURITY.md); do not post vulnerabilities publicly.
- **Conduct**: the [code of conduct](CODE_OF_CONDUCT.md) applies everywhere the project talks.

Before asking, the documentation covers most things:
[installation](docs/installation.md), [getting started](docs/getting-started.md),
[workflow](docs/workflow.md), [features](docs/features.md) and
[tools reference](docs/tools.md).
